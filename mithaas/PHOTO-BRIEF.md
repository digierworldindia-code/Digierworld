# Mithaas — photography brief

Everything the website needs, with exact filenames and sizes. Drop each file into
`assets/img/<folder>/` using the filename given and it appears automatically —
no code change needed.

**59 images in total. 31 of them are on the home page.** If you are shooting in
stages, do the home page first: it is the page most people will ever see.

---

## Export settings (applies to every image)

| | |
|---|---|
| **Format** | WebP if you can, JPEG otherwise. Keep the `.jpg` filename either way, or update the `src` in the page. |
| **Quality** | 80–85. Above that you gain nothing visible and triple the file size. |
| **Weight** | Under **350 KB** for banners, under **200 KB** for everything else. |
| **Colour** | sRGB. Not Adobe RGB — it goes dull in browsers. |
| **Do not** | upload straight off the camera. A 6000px phone photo will make the page crawl on mobile data. |

**Art direction.** Warm natural light, ideally near a window. Shallow depth of
field so one sweet is sharp and the tray behind it softens. Real serving ware —
steel trays, brass, banana leaf, the actual counter. No heavy filters, no blue
tones, no plastic-looking styling. Shoot slightly from above (about 45°) for
plated food, straight on for the counter and the shopfront.

`python3 tools/add-logo.py ~/Downloads/mithaas-logo.png` from a terminal.)

## If you can only do a few

In this order:

1. `hero/hero-sweets.jpg` — the home banner
2. `brand/mithaas-logo.png` — the logo
3. The six Mithaas Favourites
4. `restaurant/thali-hero.jpg` and `brand/story-counter.jpg`
5. `gallery/shopfront.jpg`

That covers everything visible before a visitor scrolls, which is most of the
impression the site makes.

Anything not yet supplied shows a gold-and-ivory tile with the dish name on it,
so the site never looks broken while you work through the list.
