| Code | Role | Description |
|---|---|---|
| `super_admin` | Owner / Super Admin (super) | All modules, approvals and permission management. Privileged actions are logged. |
| `accountant` | Accountant | Billing, finance, bank, GST reports. No CRM lead lists or candidate CVs by default. |
| `billing_operator` | Billing Operator | Creates invoice/cash memo drafts for allowed customers. No revenue totals, bank, GST dashboards, CRM, HR. Finalize/print individually assignable. |
| `crm_manager` | CRM Manager | All CRM data, assignments, team performance and Sheets sync status. No bank details or salaries. |
| `telecaller` | Telecaller | Own assigned leads, calls, follow-ups, meetings, visits, tasks and own stats only. |
| `sales_executive` | Sales Executive | Assigned leads, visits, meetings and quotations. |
| `hr_manager` | HR Manager | Recruitment, employees, attendance, leave, incentives and payroll. |
| `hr_recruiter` | HR Recruiter | JDs, assigned applicants, interviews, candidate timeline and scoped AI CV review. No finance, CRM or salary. |
| `payroll_manager` | Payroll Manager | Attendance, approved incentives, payroll calculation and payslips. No billing/CRM. |
| `employee` | Employee | Own attendance, leaves, payslips and assigned tasks only. |
| `auditor` | Auditor (Read Only) | Time-limited read-only access to selected registers and audit trails. Assign with an expiry date. |

## Separation-of-duties warnings

- `finance.expense.create` + `finance.expense.approve` — Same user can record and approve expenses
- `hr.payroll.calculate` + `hr.payroll.finalize` — Same user can calculate and finalize payroll
- `hr.salary.manage` + `hr.payroll.pay` — Same user can change salary and pay salary
- `finance.receipt.create` + `finance.bank.reconcile` — Same user can record receipts and confirm reconciliation
- `security.roles.manage` + `security.audit.view` — Role manager can also read the audit trail of their own changes
